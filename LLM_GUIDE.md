## Module: scripts

The `scripts` package contains several Bash scripts designed to automate various tasks in a Go development environment. It includes tools like `ai-lint.sh` for scanning Go files for AI-generated patterns, `budget-status.sh` for monitoring soft caps, and `docs-check.sh` for ensuring documentation consistency. Additionally, it features scripts for generating architecture snapshots (`architecture-snapshot.sh`) and enforcing privilege escalation policies (`escalation-lint.sh`). The package also sets up Git hooks to automate code quality checks during development (`merge-properties.sh` and `setup-git-hooks.sh`).

## Module: scripts/ci

The `scripts/ci` directory contains Bash scripts for continuous integration in a Go project. The `fast.sh` script performs quick pre-commit checks such as code formatting, linting, and budget verification, exiting on the first failure to provide immediate feedback. The `full.sh` script acts as a comprehensive pre-push gate, running extensive tests, linters, vulnerability scans, documentation generation, and other quality assurance steps before allowing a push. Both scripts utilize environment variables for configuration and exclude certain checks for performance reasons.

## Module: scripts/migrate/v1-to-v2

The `migrate.py` script facilitates the conversion of Mooncake v1 configuration files to v2 format, handling key renames, attribute collapses, and nested steps. It supports dry-run mode and processes individual files or directories containing `.yml` or `.yaml` files, outputting changes or errors to the console.
