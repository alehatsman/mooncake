## Overview

This repository contains a suite of packages that form the core functionality of a comprehensive automation tool named Mooncake. Key components include `internal/config` for robust configuration management, `internal/actions` for defining and handling resource mutations, `internal/logger` for flexible logging across different environments, `internal/executor` for task execution and management, `internal/fleet` for fleet management on Windows hosts, `agentd` as a long-running daemon exposing Mooncake's kernel over HTTP, `cmd/fleet` for managing fleet peers via CLI, `internal/events` for event handling in distributed systems, `internal/security` for secure privilege escalation and data handling, `internal/schemagen` for generating JSON Schema and TypeScript definitions from Go structs, `internal/agent` for plan confirmation and execution, `internal/facts` for collecting system facts across operating systems, and `internal/plan` for managing and validating execution plans. Together, these packages provide a powerful automation platform with features like configuration management, task execution, logging, fleet orchestration, and more.

## Module: scripts

The `scripts` package contains several Bash scripts designed to automate various tasks in a Go project. These scripts include `ai-lint.sh`, which scans Go source files for AI-generated patterns; `arch-snapshot.sh`, which generates architecture snapshots with metrics like LOC and coupling; `cap-check.sh`, which verifies soft caps defined in `CLAUDE.md`; `docs-check.sh`, which regenerates and compares documentation; `escalation-lint.sh`, which enforces privilege escalation policies; and `merge-properties.sh`, which merges auto-generated properties into manual documentation. Additionally, the package includes Git hooks for a Mooncake development environment, ensuring that code changes are validated before being committed or pushed.

## Module: scripts/ci

The `scripts/ci` package contains Bash scripts (`fast.sh` and `full.sh`) that serve as pre-commit and pre-push hooks for Go projects. The `fast.sh` script performs cheap checks like `go vet`, `gofmt`, `ai-lint`, budget checks, and documentation/schema regeneration to ensure code quality and consistency. The `full.sh` script is a more comprehensive gate, running build, test, linting, vulnerability checks, documentation/schema regeneration, architecture analysis, budget monitoring, duplication detection, and escalation policy enforcement before allowing a commit. Both scripts stop at the first failure and provide detailed output for each step.

## Module: scripts/migrate/v1-to-v2

The `scripts/migrate/v1-to-v2` package contains a Python script named `migrate.py` designed to convert Mooncake v1 configuration files to the newer v2 format. It leverages `ruamel.yaml` for YAML parsing and emitting while preserving comments. The script includes mappings such as `ACTION_RENAMES`, `FRAMEWORK_RENAMES`, `ACTIONS_WITH_NESTED_STEPS`, and `KEEP_AS_IS` to handle key transformations, nested steps, and unchanged keys. It offers a command-line interface for migrating files or directories in place or performing a dry run.
